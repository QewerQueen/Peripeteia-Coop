Peripeteia Coop — как играть вместе

Ниже по-русски, потом English.

Установка завершена. Мод уже лежит в игре. Дальше нужно только запустить игру и подключиться — командная строка не нужна.

1. Запусти игру

Запусти Peripeteia как обычно (из Steam или ярлыка).

Первый запуск после установки может занять дольше обычного: BepInEx готовит вспомогательные файлы. Если кнопки COOP в меню не видно, просто закрой и запусти игру ещё раз.

2. Открой меню COOP

В главном меню, под кнопкой выхода, появилась кнопка COOP. Нажми её — откроется панель мода.

3. Соединитесь (один ПК или локальная сеть)

  1. Хост: нажми Host game. Игра начнёт раздавать сессию и появится в списке у остальных.
  2. Второй игрок: подожди несколько секунд, пока хост появится в списке «Hosts on the local network», и нажми на его строку.
  3. Клиент: нажми Download and start the host save. Сохранение хоста скачается, и игра сама начнётся с него. Обычно скачивание запускается автоматически при подключении.
  4. Если хост не появился в списке, впиши его адрес в поле Connect by IP (формат IP:порт, например 26.12.34.56:7777) и нажми кнопку рядом.
  5. Готово — вы в одном мире.

4. Игра через интернет

В игре нет Steam-сетевого кода, поэтому для игры не по локалке нужно:

  • пробросить UDP-порт 7777 на машине хоста, или
  • использовать бесплатный VPN-меш вроде RadminVPN, Tailscale или ZeroTier и подключаться по его адресу. Хосты в VPN обычно находятся сами, а если нет — подключись через поле Connect by IP в меню COOP.

Что общее, а что личное

  • Общее: мир, NPC и враги, двери, сюжет (одна ветка «кто первый»), катсцены, награды и стартовый набор.
  • Личное у каждого: инвентарь, деньги, здоровье, патроны. Клиент хранит их в своём сохранении и может играть один.
  • Игроки могут ранить и толкать друг друга; смерть возвращает на последнюю точку сохранения, не сбрасывая мир.

Если что-то не работает

  • У обоих игроков должна быть одна и та же версия игры и мода.
  • Хост не виден в списке — проверьте, что вы в одной сети и что у обоих стоит мод (в меню есть кнопка COOP). В VPN-сетях (RadminVPN/Hamachi) подключись вручную через поле Connect by IP.
  • Кнопка COOP не появилась — перезапусти игру; первый запуск мог ещё готовить файлы BepInEx.
  • Подробности и лог: BepInEx\LogOutput.log в папке игры.

Peripeteia Coop — how to play together

Installation finished. The mod is already in the game. All that is left is to launch the game and connect — no command line.

1. Launch the game

Start Peripeteia as usual (Steam or a shortcut).

The first launch after installing may take longer than usual while BepInEx prepares its files. If the COOP button is not in the menu yet, just close and start the game once more.

2. Open the COOP menu

In the main menu, below the exit button, there is now a COOP button. Click it to open the mod panel.

3. Connect (same PC or local network)

  1. Host: click Host game. The game starts advertising and appears in everyone else's list.
  2. Second player: wait a few seconds for the host to show up under «Hosts on the local network» and click its row.
  3. Client: click Download and start the host save. The host save is downloaded and the run starts from it automatically. The download usually begins on connect.
  4. If the host is not listed, type its address into the Connect by IP field (format IP:port, for example 26.12.34.56:7777) and click the button next to it.
  5. Done — you are in the same world.

4. Playing over the internet

The game has no Steam networking, so to play outside a LAN you either:

  • forward UDP port 7777 on the host machine, or
  • use a free mesh VPN such as RadminVPN, Tailscale or ZeroTier and connect via its address. Hosts are usually found automatically over a VPN; if not, use the Connect by IP field in the COOP panel.

Shared vs. personal

  • Shared: world, NPCs and enemies, doors, the story (one first-come-first-served branch), cutscenes, rewards and the starting kit.
  • Personal per player: inventory, money, health and ammo. The client keeps them in its own save and can play alone.
  • Players can hurt and push each other; death respawns you at your last save point without resetting the world.

Troubleshooting

  • Both players must run the same game and mod version.
  • Host not listed — make sure you are on the same network and that both have the mod (the COOP button is in the menu). On a VPN (RadminVPN/Hamachi) connect manually with the Connect by IP field.
  • No COOP button — restart the game; the first launch may still have been preparing BepInEx.
  • Details and log: BepInEx\LogOutput.log in the game folder.
